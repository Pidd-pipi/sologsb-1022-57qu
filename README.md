# 稽古堂 · 公版文本注释版编辑工具

面向公版古籍整理者的章节、句子和词语级注释工作台。支持脚注、异文、背景说明与交叉引用，并可在阅读版、编辑版、校勘版之间切换，解决不同来源之间的注释冲突。

## 功能

- 按章节、句子和词语选择注释目标，维护脚注、异文、背景说明和交叉引用。
- 使用稳定 ID 保存正文与注释关系；句子修订后，失效的词级引用自动迁移到所属句，避免悬空引用。
- 自动按“引用目标 + 注释类型”汇总来源冲突，可逐条选用来源或合并正文后解决。
- 阅读版按引用展开脚注，编辑版提供正文和注释编辑，校勘版并列展示来源、异文与校记。
- 章节目录跳转、正文/注释/来源全文检索，以及下一条注释快速定位。
- 本地离线草稿自动保存；模拟接口保存按钮用于演示网络保存状态。
- 版本快照与两版差异比较，可查看句子改动、新增注释并恢复快照。
- 导出完整 HTML 阅读版或 JSON 数据，支持浏览器打印。
- 两位校注员离线批注包合并：
  - 包格式 `guji-annotation-package@v1`，带**基准版本、稳定身份（`originId`）与三级锚点（章/句/词）的原文引用和校验和**；支持文件导入，内置“校注员甲 / 校注员乙 / 旧版 v0 草稿”三个可下载样例。
  - **逐条认领**：每条意见可“认领 / 不采用”，未裁定意见不进入正文、校勘版与导出，也不会遮挡底本。
  - 正文改动后旧锚点立即标记**失效待确认 / 锚点缺失**，必须人工改挂，系统不自动硬接到别的句子；失效项只停留在合并清单。
  - **重复导入**同一批注（按稳定身份）只生效一次，自动跳过并在账本中说明来源。
  - **交叉引用**在本稿、已合并批注与同批意见之间自动回连；找不到目标即标“断链待修”，可改指或移除。
  - 导入即留存**合并前检查点**；合并失败/关闭可回到检查点，原草稿与进行中会话均随 localStorage 持久化，**重开可继续处理**。
  - **旧版兼容**：v0 旧批注包（`uid/noteType/target.token` 等字段）与旧版本地离线草稿均可自动升级后导入，旧本地 ID 改写为 `legacy:` 稳定身份。
- 快捷键：`J/K` 上/下一条注释，`[`/`]` 上/下句，`/` 聚焦搜索，`Alt+1/2/3` 切换视图，`Ctrl/⌘+Z` 撤销，`Ctrl/⌘+Shift+Z` 重做，`Ctrl/⌘+S` 模拟接口保存。
- 响应式布局：桌面使用三栏工作区，窄屏自动堆叠；所有主要按钮和编辑目标均有语义标签。

## 技术栈

- Next.js 15（App Router、静态导出）
- React 19
- TypeScript
- HeroUI + Tailwind CSS
- localStorage 离线持久化
- 浏览器内模拟接口，无后端依赖

## 本地开发

```bash
npm install
npm run dev
```

打开终端显示的本地地址。开发服务器端口由 Next.js 决定，源码未硬编码宿主端口。

合并语义（锚点失效、去重、断链、旧版迁移、检查点）的无依赖冒烟测试：

```bash
npm run test:merge
```

## 生产构建

```bash
npm install
npm run build
```

静态产物位于 `out/`。由于启用了 `output: 'export'`，不需要 Node.js 服务即可托管。

## Docker

```bash
docker build -t sologsb-1022 .
docker run --rm -p 10022:80 sologsb-1022
```

容器内 nginx 监听 `80`，根端口表将其映射为宿主 `10022`。

## 数据说明

离线草稿、版本快照和最后编辑位置保存在当前浏览器 `localStorage`。清除站点数据会删除这些内容；导出的 HTML/JSON 可用于外部备份。
